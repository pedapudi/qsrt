How QSRT’s two-bit trellis picks values

Quantile-Stratified Rate-shifted Trellis (QSRT) compresses model weights. Its supported rates trade bits between the stored code and the remembered state. The K2 rate shown here stores two bits for each weight. Seven recent two-bit codes form a 14-bit memory that changes the four values available at the next step.

The 16,384-state search in plain language

The page uses a 16×16 patch of real Kimi-K3 gate weights from layer 48, expert 17. The patch is small enough to inspect, while the compressor normally processes much larger matrices.

The Stratified Quantile Graph (SQG) assigns a replacement value to every edge of the trellis. Each of the 16,384 states represents one possible 14-bit memory. Four outgoing edges append one of the codes 00, 01, 10, or 11.

The reconstruction table is ordered from negative to positive and divided into four equal-count regions called strata. The current state selects one position, called the phase, inside every stratum. The two stored bits choose which stratum supplies the replacement value.

A Viterbi search keeps the lowest-error partial route into every state. After reading all 256 weights, it traces backward from the lowest-cost ending state to recover one complete sequence of two-bit codes. A small error at one weight can be worthwhile when the resulting state offers better values later.

The 14-bit shift register sets the next phase

The shift register contains the seven most recent two-bit codes. It contains no weight values. Appending a code discards the oldest two bits and leaves a new 14-bit state for the next trellis step.

The Walsh-Hadamard basis uses real plus and minus patterns

The Walsh-Hadamard and Fourier transforms are orthonormal changes of basis, so both preserve energy. Fourier basis vectors use sine and cosine values. Walsh-Hadamard basis vectors use +1 and −1, which permits an add-and-subtract butterfly.

A unit value at one coordinate contributes a magnitude of 0.25 to each of the sixteen normalized Walsh-Hadamard coefficients. The signs depend on the basis pattern. The bottom strip draws those sixteen computed coefficients.

Every selected weight passes through four stages

The cursor selects a weight; it does not select one of these stages. The encoder performs all four stages for every weight.

Take the selected number from the matrix.
2. Generate four reconstructions
The current state supplies one possible value in each stratum.
3. Compare full routes
Keep the lowest accumulated error entering every successor state.
4. Trace and store
Trace back the best route and store its two-bit code at this position.

The production encoder also requires the path to finish in its starting state, estimates the scale, and applies blockwise second-order error feedback (BlockLDLQ) before each trellis solve. It applies a larger reversible Hadamard rotation across coupled gate and up matrices. This page isolates the K2 path mechanism with an open path, plain squared error, and a rowwise Hadamard control.
