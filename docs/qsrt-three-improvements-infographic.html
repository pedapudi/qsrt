No quantization background required

How QSRT stores weight matrices with a trellis.

A language model stores learned numbers, called weights, in rectangular tables called matrices. QSRT compresses a matrix block by choosing a route through a fixed directed graph called a trellis. The model file stores compact bits identifying that route. When the model runs, a decoder follows the stored route and rebuilds approximate matrix values.

00 · foundation

Start with one number, then build QSRT.

Each drawing adds one idea. The first two drawings explain how to store each number with two bits, a process called two-bit quantization. The last two show how the trellis links choices across an ordered list of numerical targets instead of rounding every number independently.

STEP 1 A weight changes a signal.

Multiply an input by a weight, then add it to other weighted inputs. Training chooses the weights.

STEP 2 Two bits select four choices.

Quantization replaces a detailed weight with a short code. The encoder and decoder share a fixed list that assigns one approximate number to each code, called a lookup table. In this example, code 10 selects the third entry, +0.3.

STEP 3 A trellis links choices across a list of target numbers.

The encoder begins with a list of numbers that the decoder should rebuild approximately. Each number is called a target. A sequence index is its position in the list: index 0 means first, index 1 means second. At each index, two stored bits choose one outgoing arrow, called a branch. The arrow moves from the current history state to the next history state. That new state changes the choices available for the next target.

STEP 4 One search chooses the whole path.

Viterbi search keeps the cheapest partial route to each state. Requiring the final state to equal the starting state is called tail-biting.

The problem: rebuild 256 detailed numbers from a few stored bits per number

QSRT must replace every detailed number in a 256-number tile with an approximate value while storing only two, three, or four branch bits for each number. Independent two-bit rounding always chooses from the same four approximate values. A K2 trellis also stores two bits per number, but its history state changes which four approximate values are available at the next position.

The trellis encoder searches the legal linked choices and keeps the closed path whose 256 reconstructed values produce the lowest total error. The stored output is the path’s compact branch sequence. During model execution, the decoder replays those branches to rebuild the approximate tile.

The production trellis does not receive an untouched source-matrix entry directly. QSRT decodes the source weights and applies a reversible Hadamard mixing transform that preserves the expert calculation. BlockLDLQ then adjusts later targets to compensate for earlier quantization errors.

QSRT cuts the adjusted matrix into 16-by-16 tiles. For each tile, QSRT visits all 256 cells in the fixed order required by the decoder and writes each adjusted value into a list. That 256-target list is the trellis input. The fixed order gives the encoder and decoder the same mapping from each sequence index to one tile cell.

Input

One list of 256 adjusted targets, plus the fitted tile scale. Each list entry comes from one cell of a transformed 16-by-16 tile. The tile scale expands or shrinks the reconstruction table to fit those targets.

Sequence index

Index t from 0 through 255 gives one target’s position in the list. Index 0 means the first target and index 255 means the last. The fixed position also tells the decoder which tile cell it is rebuilding.

Node

A node means “the decoder is at sequence index t with this history register.” It is encoder memory rather than a model neuron or activation.

Edge choice

One K-bit branch chooses an outgoing edge. With two stored choice bits, called K2, a node offers four edges. K3 offers eight edges, and K4 offers sixteen. Each edge specifies the approximate value for target t and the history register for index t + 1.

Output and goal

The output is one packed branch per target. Viterbi chooses the closed branch sequence with the lowest sum of squared differences between the reconstructed numbers and all 256 adjusted targets.

The fourteen memory bits and the two stored choice bits form a sixteen-bit edge. QSRT shuffles those edge bits into a table position, called a rank. The frozen T12 table is a 4,096-byte list that turns the rank into a small eight-bit floating-point number.

What the letters in QSRT mean

QSRT is the Quantile-Stratified Rate-shifted Trellis codec. A codec is a method for compressing and rebuilding data. Here it represents one weight at a time, which engineers call a scalar representation.

  • Quantile-stratifiedEvery working-memory setting offers approximate numbers from several low-to-high portions of the available range. One setting cannot offer only small or only large values.
  • Rate-shiftedThe same trellis supports K2, K3, and K4. The number after K gives the stored choice bits per weight. QSRT fixes the choice for each small model calculator and trades bits between its paired rectangular weight matrices.
  • Trellis codecThe encoder searches a constrained path across a sequence of weights. The runtime reconstructs weights by replaying the stored branches through a frozen table.
QSRT adds more work around the one-number-at-a-time trellis. A mixture-of-experts model contains many small calculators called experts. A coupled Hadamard transform spreads unusually large numbers before encoding. BlockLDLQ uses earlier numerical errors and examples of typical inputs to improve later choices. Kimi-K3 QSRT also promotes selected experts to a high-quality four-bit representation called X4T. It stores calculations outside the experts in an eight-bit representation called MXFP8. The GLM experiments below target the one-number-at-a-time trellis.
EXL3 and QSRT

The shared trellis idea and where the complete formats differ.

A language model is software trained to predict the next piece of text. Training fills the model with billions of learned numbers called weights. Each weight controls how strongly one internal signal affects another. EXL3 and QSRT compress those weights so the model needs less file storage and less memory on the graphics processors that run it.

Smaller files require approximate reconstruction

Before compression, many detailed weights sit together in rectangular tables called matrices. Lossy compression stores less data by allowing controlled numerical differences. An offline program called an encoder chooses the compact codes. In the drawing, it stores detailed weight +0.314 as code 010, which contains three zero-or-one digits called bits. A decoder reads that code and rebuilds +0.301, which differs from the original by 0.013. Replacing detailed values with compact codes and approximate values is called quantization.

An encoder chooses the codes once, while the model file is built. A decoder reads the chosen codes whenever the model runs. If reconstruction errors alter too many internal signals, the model's text predictions get worse. The encoder therefore searches for codes that keep the important errors small.

A trellis is a directed graph repeated across the ordered weights. At one weight, an arrow selects an approximate value and moves to a temporary memory state. That state restricts the arrows available for the next weight. The closest value at one position can force a worse choice later, so the encoder searches complete paths. In the drawing, total error adds the squared differences for two weights: 0.0125 is much smaller than 0.6725. The decoder does not search; it follows the stored path.

How EXL3 compresses one weight matrix

ExLlamaV3 is software for running compressed language models. Its EXL3 weight format specifies the stored codes, supporting data, and decoder rules. The EXL3 encoder processes one rectangular weight matrix at a time.

  1. Spread unusually large values. A signed Hadamard transform mixes the matrix with fixed addition and subtraction patterns. This makes the values more even before compression. EXL3 stores enough transform information to reverse the mixing.
  2. Search linked reconstruction choices. At every matrix position, each outgoing arrow, called an edge, produces an approximate weight and a next history state. The history state is temporary memory that records enough earlier choices to restrict the next choice. A fixed calculation that converts an edge number into an approximate weight is called a procedural codebook. EXL3 supplies codebooks called MCG and MUL1. One fitted multiplier, called a scale, expands or shrinks the available approximate values to suit the matrix.
  3. Account for earlier errors. An error-feedback calculation called BlockLDLQ uses examples of signals that will enter the matrix. It changes later numerical targets so later choices can compensate for earlier reconstruction errors.
  4. Store the winning route. A closed route ends in the same history state where it began, a condition called tail-biting. A search method called Viterbi keeps the partial route with the lowest accumulated reconstruction error at each history state. It then recovers the closed route with the lowest total reconstruction error. The compact choice stored for one matrix position is called a branch. EXL3 packs the branch bits with scales and transform data. During model execution, the decoder repeats the codebook calculation for each stored branch and rebuilds the matrix.

What QSRT keeps and what it changes

QSRT builds on the trellis machinery used by EXL3. It changes which approximate value each edge produces and coordinates several matrices that work together.

  1. Keep the shared foundation. QSRT retains EXL3-style signed Hadamard mixing within each matrix, BlockLDLQ error feedback, trellis state updates, tail-biting closure, Viterbi search, fitted scales, and packed branch bits.
  2. Change which approximate value each edge produces. QSRT uses a labelled graph and finite reconstruction rule called the Stratified Quantile Graph, or SQG. Its production table is a 4,096-byte list of eight-bit values called T12. K2, K3, and K4 mean two, three, and four stored branch bits per weight. They use the same graph construction. The branch size changes how the sixteen edge bits divide between history and the stored branch.
  3. Optimize a complete routed expert. In a mixture-of-experts model, a router chooses a few small calculators for each piece of text. Each calculator is an expert. Two expert matrices, called gate and up, create aligned intermediate values. A third matrix, called down, maps their product back into the model's main stream of intermediate numbers. QSRT can transform and score those three matrices as one connected calculation.
  4. Allocate and package complete experts. Two related records ordinarily use three branch bits per weight apiece. QSRT may give one record four bits and the other two bits, so their combined branch payload remains six bits. For Kimi-K3, QSRT can also use X4T for a selected whole expert. X4T reproduces the official four-bit expert values while compressing their supporting scales. The QSRT container groups complete expert records without recording the number of GPUs that will serve the model.
Shared foundation

Both systems spread difficult matrix values, fit numerical scales, use error feedback based on typical inputs, search a tail-biting trellis with Viterbi, store compact branch bits, and reconstruct one approximate value for each encoded matrix position.

Reconstruction graph and law

EXL3 uses its MCG or MUL1 calculation to map trellis edges to approximate values. QSRT uses the SQG-labelled graph and the finite T12 value table. A different edge-to-value rule can change the best path even when the source weights and number of stored branch bits stay the same.

Optimization scope

EXL3 conditions and encodes each rectangular matrix. QSRT retains that per-matrix machinery and adds a reversible mixing transform across the complete expert. It can reconstruct the gate and up matrices before estimating how to encode the down matrix.

Allocation and storage

EXL3 produces ExLlamaV3 packed arrays for each encoded matrix. The named Kimi-K3 comparison checkpoint may combine those arrays with higher-quality expert storage, but the repository has not counted that mix directly from the checkpoint files. QSRT assigns one fixed branch-bit choice to each expert, supports a whole-expert X4T endpoint for Kimi-K3, and stores complete expert records in a tensor-parallel-independent container.

The comparison requires two measurements

Count every byte in the finished EXL3 and QSRT checkpoint files. Then give the same evaluation text to EXL3, QSRT, and a separate high-quality reference model called the teacher. Forward KLD measures how far each candidate's output probabilities move from the teacher's probabilities; lower is better. The evaluation text must come from documents that were not used to choose codec settings. Hold all model weights outside the compared expert format fixed so they cannot determine the KLD result.

No complete EXL3-versus-QSRT quality result exists yet. A synthetic reconstruction test or a local weight-error result cannot establish checkpoint quality. QSRT meets the stated target only if its complete serialized checkpoint is smaller and its paired document-disjoint teacher-to-candidate forward KLD is lower than EXL3's. The teacher must be a third high-quality reference, separate from both candidates.

What “up weight” and “down weight” mean

An up weight is one learned number in the up matrix. It contributes to one intermediate value calculated from the expert input.

A down weight is one learned number in the down matrix. It contributes to one output value calculated from the multiplied intermediate values.

A quantization grid is a set of approximate values that the decoder can rebuild. It is not a matrix. Saying “up grid weight” mixes these two ideas; the rest of this explainer uses “up weight” or “up-matrix reconstruction values.”

Rejected mechanism

Train the reconstruction values on what the encoder really sees.

A branch does not store a floating-point weight. It identifies one entry in a shared reconstruction table. The frozen T12 table was designed to approximate a reference bell-shaped distribution. The production residual diagnosis found nearly Gaussian values, negligible adjacent correlation, and complete table occupancy. A finite-E4M3 fixed-path update reduced pooled SSE by only 0.00175%.

Score scalar paths by their downstream damage.

Two equally sized weight errors can have very different effects on the model. Fit rows supply an input metric and captured output gradients supply a downstream metric. Their product estimates how strongly an edge error changes later model outputs. That estimate becomes an additive edge cost, so the production Viterbi dynamic program remains usable. The first result must show that this score predicts document-disjoint forward KLD better than routed squared error. The same validated score then prices mixed K3/K4 and residual candidates for exact-byte allocation.

What to test when a promising expert deserves more storage

These allocation follow-ups begin only after one of the two active codec proposals passes its evidence gate. K3, K4, and K5 mean that each encoded matrix number stores three, four, or five trellis branch bits. A higher rate gives the path more choices but increases the finished checkpoint.

Gate and up cannot always choose rates independently.The GLM mixed-rate experiment encodes the gate, up, and down matrices separately, so it can compare unequal gate/up rates. Kimi's coupled transform first mixes gate and up rows; after that mixing, both must share one rate. A Kimi candidate with unequal rates must drop the transform and count the quality it loses.
Kill a diffuse residual idea early.A residual is the difference left after ordinary reconstruction. For a 256-position tile, continue only if the largest curvature-weighted residual holds more than 6% of the tile's weighted error, or the two largest hold more than 10%. The complete correction oracle must also save more error per added serialized byte than K4.
K5 needs a different reconstruction endpoint.The production quantizer supports K2 through K4. Repository high-rate tests found that its finite E4M3 values limited K5 quality. A K5 diagnostic must use the research-only FP16 reconstruction endpoint and count its storage; production E4M3 K5 is an established negative control.
The GLM EXL3 rate map passes an independent arithmetic check. Across 75 mixture layers, 28,638 four-bit projections and 81 five-bit projections add 28,800 bit-units above an all-three-bit assignment: 28,638 + 2 × 81 = 28,800. The documented layer budget gives the same total: 75 × 384 = 28,800. This confirms the parsed map, but the map remains a sampling guide rather than proof that EXL3 chose the best rate for each QSRT candidate.
Ideas removed after adversarial review: per-coordinate reciprocal up/down balancing increased pooled error in a real Kimi two-bit SQG study, and the two-position synthetic trellis exaggerated its apparent value. Exhaustive KLD search across every gate/up path has no feasible production computation. Pair trellises, residual streams, and entropy-coded paths remain deferred until the format-preserving experiments above transfer on real production paths.

Primary sources · explicit transfer limits

A research map for making QSRT better.

Quantization stores approximate model weights in fewer bytes. Research from signal compression, trellis coding, and low-bit language models supplies possible improvements. GLM-5.2 uses a mixture-of-experts layer, which routes each input to a small subset of many expert calculations. Every improvement still has to survive QSRT's directed graph, fixed GPU decoder, expert routing, and complete-checkpoint quality test.

Published evidenceA paper establishes a result for its named signals, models, bit rates, objectives, and decoder. The result is not automatically a QSRT result.
Repository evidenceA synthetic source, real tile, complete expert, or complete layer supports only the scope that was measured. Local squared error does not establish model KLD.
Proposed transferA QSRT experiment must preserve the production graph, scale search, serialized bytes, and runtime constraints. It must also preserve BlockLDLQ, which feeds earlier quantization errors into later encoding choices.
Evidence ladder

A small result can reject an idea. A pass only permits the next test.

Routing, co-routed experts, later transformer layers, and GPU arithmetic create effects that an isolated coefficient cannot contain. Each rung therefore answers one bounded question.

Complete checkpoint

Paired documents test forward Kullback–Leibler divergence (KLD), which measures how far candidate output probabilities move from a reference. Exact files establish the model-size comparison.

AND
QSRT forward KLD < EXL3 forward KLDUse paired document-disjoint prompts, one separate high-quality reference, identical non-expert weights, and a repeatability control.

No complete GLM-5.2 candidate has passed this gate. The accepted eager per-expert measurement reproduced unchanged and direct-return identity controls bit for bit on one published 2,048-token BF16 reference context. On that context, down refitting improved uniform-K3 mean KLD but remained above EXL3. The available reference has no second document, so the result cannot establish document-disjoint checkpoint quality.

Signal coding · transform

Spread correlated or extreme values before quantization

adopted principle
Source demonstrated

The discrete cosine transform concentrates correlated signal energy. JPEG applies block transforms before coefficient quantization.

QSRT translation

The qualified Hadamard transform spreads weight outliers while retaining a cheap inverse. A transform across a nonlinear expert boundary needs an algebraic closure proof.

GLM-5.2 test

Compare identity and legal low-cost transforms on complete experts with identical trellis payload, scale search, and decoder work.

Failure mode

Neighboring matrix cells do not have image pixels' spatial meaning. A visually useful frequency basis can increase model-weight error.

Nasir Ahmed, T. Natarajan, and K. R. Rao. “Discrete Cosine Transform.” IEEE Transactions on Computers C-23(1):90–93, 1974. Gregory K. Wallace. “The JPEG Still Picture Compression Standard.” IEEE Transactions on Consumer Electronics 38(1), 1992.

Signal coding · table fitting

Alternate complete assignments with reconstruction-value updates

rejected on measured domain
Source demonstrated

Lloyd's conditions alternate assignment to the nearest reconstruction region with an update to that region's average reconstruction value, called its centroid.

QSRT translation

Hold the table fixed while Viterbi assigns complete paths. Then hold the paths fixed while centroids update used entries in the finite eight-bit E4M3 format.

GLM-5.2 evidence

All 4,096 table entries were occupied in each measured matrix. The E4M3 fixed-path update improved pooled sum of squared errors (SSE) by only 0.00175% on eight experts.

Decision

Do not build the alternating update on the measured residual domain. Reopen the idea only if another model or loss-weighted diagnosis shows material table headroom.

Stuart P. Lloyd. “Least Squares Quantization in PCM.” IEEE Transactions on Information Theory 28(2):129–137, 1982.

Signal coding · feedback

Feed committed error into later encoding choices

adopted principle
Source demonstrated

Differential coding predicts a value, then quantizes the remaining difference, called an innovation. Noise shaping moves error toward directions that a reconstruction operator attenuates.

QSRT translation

BlockLDLQ feeds earlier quantization error into later blocks using an input-covariance geometry.

GLM-5.2 test

Measure residual correlation after feedback and compare legal coefficient orderings under the same complete paths and held-out objective.

Failure mode

A Fourier-frequency filter has no automatic model analogue. The useful low-sensitivity directions must come from model loss rather than image or audio frequency.

N. S. Jayant. “Digital Coding of Speech Waveforms: PCM, DPCM, and DM Quantizers.” Proceedings of the IEEE 62(5), 1974. Petros T. Boufounos and Alan V. Oppenheim. “Quantization Noise Shaping on Arbitrary Frame Expansions.” EURASIP Journal on Applied Signal Processing, 2006.

Trellis structure · foundation

Choose a low-error path through linked reconstruction choices

core mechanism
Source demonstrated

Trellis-coded quantization uses path constraints and Viterbi search to improve shaping over independent scalar quantization on memoryless and Gauss–Markov sources.

QSRT translation

QSRT stores one branch per target and uses a history state to change the available reconstruction values at the next target.

Repository evidence

On an independent Gaussian source, production SQG labels measured 2.62% lower K2 SSE and 3.00% lower K3 SSE than the MCG control on the same graph.

Evidence limit

Gaussian source distortion does not include transformed GLM weights, BlockLDLQ feedback, routed activations, or forward KLD.

Michael W. Marcellin and Thomas R. Fischer. “Trellis Coded Quantization of Memoryless and Gauss–Markov Sources.” IEEE Transactions on Communications 38(1):82–93, 1990.

Trellis structure · vector symbols

Encode an aligned gate/up pair as one trellis symbol

deferred
Source demonstrated

Trellis-coded vector quantization replaces each scalar reproduction with a vector and trains the vector alphabet under path constraints.

QSRT translation

One four-bit branch could rebuild two aligned gate/up coefficients, retaining two payload bits per weight while pricing their joint effect through the gated activation.

Required evidence

A production-length CPU reference must beat both scalar bases before CUDA packing, pair-aware feedback, and a new decoder format are justified.

Cost or risk

Joint symbols forfeit independent gate/up rates and can conflict with the qualified coupled transform. A 4.90% Kimi pair-codebook oracle did not include trellis paths.

Thomas R. Fischer, Michael W. Marcellin, and Min Wang. “Trellis-Coded Vector Quantization.” IEEE Transactions on Information Theory 37(6):1551–1566, 1991.

Trellis structure · residual stage

Add a second trellis only when residual error is concentrated

deferred
Source demonstrated

Residual trellis-coded vector quantization encodes the remaining error in successive stages to control codebook complexity.

QSRT translation

A base path plus a bounded correction stream could target errors left by K3. Every correction, exponent, selector, offset, and alignment byte must enter the rate.

Numerical gate

Continue only if the top curvature-weighted residual carries more than 6% of tile error, or the top two carry more than 10%, and the oracle beats K4 per exact added byte.

Cost or risk

A second stream adds decoder work and random-access metadata. Gaussian-like diffuse residuals make a K4 promotion more efficient.

Arda Aksu and Masoud Salehi. “Design, Performance, and Complexity Analysis of Residual Trellis-Coded Vector Quantizers.” IEEE Transactions on Communications 46(8):1020–1026, 1998.

Trellis structure · modern LLM codec

Use a high-dimensional bitshift trellis with incoherence processing

inherited foundation
Source demonstrated

QTIP combines Hadamard incoherence, bitshift trellises, tail biting, two-dimensional hybrid tables, and BlockLDLQ for low-bit language-model weights.

QSRT translation

QSRT inherits the stateful bitshift path, tail-biting closure, transform conditioning, and dense-covariance feedback family.

Published measurement

QTIP reports 0.068–0.069 two-bit MSE for its Gaussian trellis codes, compared with 0.089 for its eight-dimensional QuIP# control and 0.118 for scalar Lloyd–Max.

Remaining question

Reusing a Gaussian table does not optimize GLM's transformed and feedback-adjusted residuals or its downstream loss.

Albert Tseng, Qingyao Sun, David Hou, and Christopher De Sa. “QTIP: Quantization with Trellises and Incoherence Processing.” Advances in Neural Information Processing Systems 37, 2024.

Loss objective · input curvature

Weight coefficient errors by the inputs that use them

adopted principle
Source demonstrated

QuIP minimizes an input-covariance-weighted quadratic error after transformations make the weights and important directions less aligned with coordinate axes.

QSRT translation

QSRT's dense input covariance and BlockLDLQ feedback already use the one-sided objective for gate, up, and expert-local down encodes.

GLM-5.2 result

One-sided routed-input curvature improved held-out local expert-output SSE, then increased mean full-model KLD by 2.3453% relative to uniform K3 on the scored context.

Decision

Reject one-sided input covariance as a path-selection objective. The result motivates the missing output factor rather than weakening its requirement.

Jerry Chee, Yaohui Cai, Volodymyr Kuleshov, and Christopher M. De Sa. “QuIP: 2-Bit Quantization of Large Language Models With Guarantees.” Advances in Neural Information Processing Systems 36, 2023.

Transform · shaped vector code

Combine randomized Hadamard mixing with a shaped vector alphabet

partial transfer
Source demonstrated

QuIP# adds fast randomized Hadamard incoherence, blockwise recovery tuning, and an eight-dimensional E8 lattice codebook built from a regular arrangement of reconstruction vectors.

QSRT translation

The Hadamard and recovery principles transfer. A general E8 codebook does not preserve QSRT's trellis decoder or its exact gated-expert closure.

Useful experiment

Use shaped vector codes as an offline oracle for remaining distortion after the scalar trellis, then compare a deployable pair table with that ceiling.

Cost or risk

Dense vector lookup and unrestricted hidden rotations increase runtime or cross the coordinatewise nonlinear boundary incorrectly.

Albert Tseng, Jerry Chee, Qingyao Sun, Volodymyr Kuleshov, and Christopher De Sa. “QuIP#: Even Better LLM Quantization with Hadamard Incoherence and Lattice Codebooks.” Proceedings of the 41st International Conference on Machine Learning, PMLR 235:48630–48656, 2024.

Loss objective · downstream curvature

Price each path by its estimated effect on model probabilities

first priority
Source demonstrated

Model-Preserving Adaptive Rounding approximates full-model forward-KL curvature with output and input factors. It reports about 30% lower KL than LDLQ on its evaluated models and quantizers.

QSRT implementation

The recurrence, output factor, factor artifact, frozen-scale candidate path, and production-sized CUDA traversal are implemented while preserving the scalar graph and bytes.

GLM-5.2 gate

The score must predict document-disjoint forward KLD better than routed expert-output SSE. A pass also supplies the damage score for mixed K3/K4 allocation.

Cost or risk

The forward-only runtime still needs bounded output-gradient capture. Identity-curvature closure checks code and dimensions but says nothing about downstream-loss prediction.

Loss objective · routed sampling

Represent both common traffic and poorly sampled experts

measurement requirement
Source demonstrated

MoEQuant identifies unequal samples across experts and unequal affinity between samples and their selected experts as quantization problems.

QSRT translation

Natural routing frequency defines deployment quality. A separate support-balanced diagnostic can expose rare-expert failures without silently redefining production traffic.

GLM-5.2 policy

Freeze the expert reservoirs, distinct-document support, importance weights, shrinkage, and identity fallbacks before any candidate score is visible.

Failure mode

Unweighted oversampling of rare experts changes the optimized distribution and can worsen the average model that users actually run.

Xing Hu, Zhixuan Chen, Dawei Yang, Zukang Xu, Chen Xu, Zhihang Yuan, Sifan Zhou, and Jiangyong Yu. “MoEQuant: Enhancing Quantization for Mixture-of-Experts Large Language Models via Expert-Balanced Sampling and Affinity Guidance.” arXiv:2505.03804, 2025.

Loss objective · vector assignment

Use second-order information to assign and initialize vector codes

oracle first
Source demonstrated

GPTVQ interleaves Hessian-aware vector assignment with updates to remaining columns. VPTQ adds channel-independent refinement plus residual and outlier options.

QSRT translation

Use the methods to initialize or bound a finite gate/up pair table under the same two-sided metric used for scalar paths.

Required evidence

A pair table must beat both production coupled scalar coding and activation-aligned scalar coding on complete paths and exact bytes.

Cost or risk

Unstructured vector tables grow exponentially. Residual and outlier planes change the uniform-rate claim and require new GPU packing.

Loss objective · reconstruction grid

Fit finite reconstruction values against weighted error

conditional test
Source demonstrated

LeanQuant learns quantization grids against an inverse-Hessian score, a second-order proxy for the loss caused by rounding, instead of using a fixed min–max grid.

QSRT translation

Fit the existing finite E4M3 table on production transformed residuals and curvature weights while retaining hard Viterbi reassignment.

Early gate

Confirm that the GPU decoder can address the intended table scope. A single shared table has less model-specific freedom than one table per layer.

Failure mode

A diagonal weight can miss gate/up cancellation and expert co-routing. Frequent entries can move at the expense of tail coverage.

Recovery · learned codebooks

Alternate continuous table updates with discrete code reassignment

after transfer
Source demonstrated

AQLM learns additive codebooks against activation error and tunes transformer blocks. PV-Tuning explicitly alternates continuous parameters with discrete assignments at one and two bits.

QSRT translation

Tune only permitted table entries, scales, and down targets. Repack hard paths and finite table values after each discrete update.

Entry condition

Use behavioral recovery only if hard post-training candidates improve faithful local metrics yet miss pre-registered full-model KLD and task margins.

Cost or risk

Every discrete update requires another encode. Full-model weight tuning changes the source and expands data provenance and compute requirements.

Vage Egiazarian, Andrei Panferov, Denis Kuznedelev, Elias Frantar, Artem Babenko, and Dan Alistarh. “Extreme Compression of Large Language Models via Additive Quantization.” ICML 2024, PMLR 235:12284–12303. Recovery · two-bit learning

Expect a representation change below three bits

strategic warning
Source demonstrated

ParetoQ reports a learning transition between two and three bits: models at two bits or below change their learned representations more substantially during recovery.

QSRT implication

Format-only post-training improvements may reach diminishing returns at the strict two-bit endpoint.

GLM-5.2 use

Keep bounded teacher-KL recovery in the roadmap if scalar path improvements transfer locally but cannot close the complete-model gap.

Evidence limit

ParetoQ studies trained scalar formats on other model families. It does not establish that a trellis table can recover GLM-5.2.

Allocation · exact rate-distortion

Spend each added byte where it removes the most validated damage

endgame
Source demonstrated

Entropy-constrained quantization minimizes distortion plus a rate penalty. Discrete bit-allocation methods handle irregular measured rate-distortion curves.

QSRT translation

Score every decoded K3, K4, and permitted residual candidate with one validated loss predictor, then solve the global exact-byte allocation below EXL3 size.

GLM-5.2 opportunity

Per-matrix rates are finer than whole-expert allocation because gate, up, and down can have different sensitivity. Dense rate stacks and their directory must be counted.

Failure mode

Nominal bits per weight omit fixed tables, scale planes, selectors, padding, and alignment. A proxy allocator is unsafe if its damage score does not predict held-out KLD.

Philip A. Chou, Tom Lookabaugh, and Robert M. Gray. “Entropy-Constrained Vector Quantization.” IEEE Transactions on Acoustics, Speech, and Signal Processing 37(1):31–42, 1989. Transfer JPEG's optimization principles without copying its bitstream

poor production default

JPEG exploits spatial frequency, zig-zag runs, and Huffman coding. JPEG2000 adds wavelets, context arithmetic coding, and embedded block truncation.

Variable-length streams and serial context decoding weaken constant stride, bounded expert access, and balanced routed GPU work.

preprint · later

BCJR-QAT uses temperature-controlled forward–backward path probabilities so gradients can pass through a trellis during quantization-aware training.

Expert function · asymmetric target

Fit the down target to reconstructed upstream activations

retain for confirmation
Related source principle

Asymmetric calibration fits a quantized layer against an exact source output so accumulated upstream error enters the target.

QSRT translation

Freeze quantized gate and up matrices. Fit a continuous down target from their rebuilt hidden rows to the source expert output, then quantize that target normally.

GLM-5.2 result

Seven of eight experts accepted re-encoded down targets. On one full-model context, the panel reduced uniform-K3 mean KLD by 1.8269% and recovered 87.3960% of K3's excess above EXL3.

Evidence limit

The refit remained 0.2691% worse than EXL3. One context cannot estimate document-level transfer, and position-level wins were fewer than losses despite the lower mean.

The direct QSRT mechanism is an application of asymmetric reconstruction. Related primary source: Yuhang Li, Ruokai Yin, Donghyun Lee, Shiting Xiao, and Priyadarshini Panda. “GPTAQ: Efficient Finetuning-Free Quantization for Asymmetric Calibration.” ICML 2025, PMLR 267:36690–36706. The GLM measurements are repository evidence rather than a result reported by GPTAQ.

Two format-preserving ideas remain active. The two-sided encoder is implemented and still has the strongest published KLD rationale, but real GLM factors and KLD remain unmeasured because output-gradient capture is missing. Down refitting improved mean KLD relative to uniform K3 on one context and advances to document-replicated confirmation. Finite-E4M3 table training and one-sided input-covariance path selection are rejected on the measured GLM domain.
